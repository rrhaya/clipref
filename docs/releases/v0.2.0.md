Save logs with fewer repeated options and retrieve their paths later.

- Set the default save directory and extension in a configuration file.
- Use `--clipboard` from launchers and macOS Shortcuts.
- Choose a filename with `--name startup-error.log`.
- List recent saved paths with `clipref list`, or copy the newest with `clipref last`.
- Follow the English or Japanese macOS Shortcut setup guide.

```sh
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/rrhaya/clipref/v0.2.0/install.sh | bash'
```

Configuration is literal data, not shell code. History stores paths, not log contents.
Saved files and history records remain private. History is not deleted automatically.

Homebrew distribution is still being prepared; use install.sh for this release.
