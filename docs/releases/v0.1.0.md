Initial release for macOS.

- Save clipboard text or piped input to a local file.
- Print and copy its absolute path.
- Choose the save directory and extension.
- Install with one command and select a release tag.

```sh
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/rrhaya/clipref/v0.1.0/install.sh | bash'
```

No runtime dependencies beyond macOS standard commands.

初回リリース。macOSでクリップボードやパイプ入力をファイルに保存し、絶対パスをコピーします。
