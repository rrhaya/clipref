Save clipboard text with `pbe`. Existing scripts and Shortcuts can still use `clipref`.

- New save paths show the local date and time down to the second, such as `20261126170042-Ab3xY7/input.txt`.
- Default saves are grouped under `${TMPDIR:-/tmp}/clipref-<user-id>`. Move that folder to the Trash to clear those saves in one step.
- Both command names share configuration and history.

`pbe` でクリップボードを保存できます。既存のスクリプトやショートカットからは `clipref` も使えます。
保存フォルダ名に秒までの日時が入り、既定の保存先はフォルダごとゴミ箱へ移せます。
